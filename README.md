# סוכר בסל 🧺

**צלמו קבלה מהסופר — ותוך דקה תדעו מה בסל מעלה סוכר, ובמה כדאי להחליף.**

🔗 **[לאתר החי — לחצו כאן](https://victoria-aflalo.github.io/sukar-basal/)**

## למי זה מיועד?

לאנשים עם סוכרת טיפוס 2 או טרום-סוכרת (ולמשפחות שלהם) שרוצים לקנות נכון — בלי להרשם, בלי לספור קלוריות, ובעברית פשוטה. האתר בנוי במיוחד לגילאי 50–75: טקסט גדול, כפתורים ברורים, פעולה אחת למסך.

## מה האתר עושה?

- **סריקת קבלה** — מצלמים קבלה (או מעלים תמונה מהגלריה, או PDF) וכל מוצר מקבל ציון: ירוק 🟢 / צהוב 🟡 / אדום 🔴 — תמיד צבע + סמל + מילה, גם למי שלא מבדיל צבעים. לכל מוצר אדום מוצעת חלופה בריאה יותר, עם המחיר החי שלה היום.
- **תפריט יומי** — 12 ארוחות מומלצות (בוקר, צהריים, ערב, נשנושים) מורכבות כולן ממוצרים בציון ירוק, עם כמויות אמיתיות למנה ("2 ביצים מתוך 18"), מחיר חי פרופורציונלי, וסיכום חלבון/פחמימות/שומן לארוחה.
- **התאמה אישית** — מזינים משקל, גיל ופעילות גופנית, והיעדים התזונתיים מחושבים לפי הנחיות ADA ומשרד הבריאות. הנתונים נשמרים רק בטלפון שלכם.
- **פרטיות מלאה** — כל הסריקה מתבצעת בדפדפן שלכם. התמונה לא נשלחת לאף שרת.

## מקורות המידע

הציונים והיעדים מבוססים על הנחיות [ADA 2026](https://doi.org/10.2337/dc26-s013), [ADA MNT 2019](https://doi.org/10.2337/dci19-0014), [PROT-AGE](https://doi.org/10.1016/j.jamda.2013.05.021) ו[משרד הבריאות](https://me.health.gov.il/older-adult/keep-me-healthy/common-conditions/diabetes-type-2/). הערכים התזונתיים מתוויות המוצרים (Open Food Facts) וממאגר USDA. המחירים מתעדכנים מדי יום מקבצי המחירים החוקיים של הרשתות.
