# סוכר בסל (Sukar BaSal)

צלמו קבלה מהסופר → כל מוצר מקבל דירוג ירוק/צהוב/אדום לסוכרתיים מסוג 2, עם חלופות קונקרטיות, מחירים אמיתיים ואיפה קונים. בלי הרשמה, בלי שרת - כל סריקת ה־OCR מתבצעת בדפדפן בלבד (Tesseract.js, heb+eng).

- אתר סטטי (GitHub Pages מתיקיית `docs/`), עברית RTL, מכוון קהל 50-75 (גופן גדול, ניגודיות WCAG AA, יעדי מגע 48px+)
- מחירים אמיתיים מקובצי חוק שקיפות המחירים (אותה צנרת של [כמה-התייקרה](https://github.com/victoria-aflalo/kama-hityakra))
- סלים לדוגמה עם מחיר למנה והשוואת רשתות, שיתוף רשימת החלפות לוואטסאפ
- בסיס רפואי: ADA Standards of Care 2026 + ההמלצות התזונתיות של משרד הבריאות. הכוונה כללית - לא ייעוץ רפואי.

נבנה על ידי ויקטוריה אפללו.
